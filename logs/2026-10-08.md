### Engine core (this increment)
- Compact IR: interned string pool + columnar typed arrays (`kind`/`num`/`str`),
  formula & numFmt maps, merges (TDD §6.1).
- Reader: format/encryption sniffing, CSV delimiter+encoding detection,
  SheetJS→IR adapter (dense, one sheet at a time), feature inventory via zip
  listing, decrypt wrapper, zip-bomb guards, progress + cooperative abort.
- Matching: table detection (header/data-range/total rows), sheet pairing,
  column matching, key detection (BR-C1 + composite), key-mode and order-mode
  row matching (FNV-1a hashing, Myers via `diff-sequences`, churn guard,
  similarity pairing, moved detection).
- Cell comparison: normalization (BR-C4/BR-C5), formula-aware kinds, positional
  baseline for the contrast line.
- Formula subsystem: tokenizer, reference model + relative form, translation
  (BR-C3), Pratt parser (Excel precedence), evaluator (memo + cycle detection),
  functions via `@formulajs/formulajs` + own `*IF(S)` criteria parser.
- Risk checks CHK-01..10 + ROW_ADDED/REMOVED/CELL_EDIT/RECALCULATED, ordering
  BR-C6.
- CLI: `sheet-diff old new [--json] [--key ...]` (+ `merge` placeholder wired
  to come with M6/M7).

## Compare fixtures landed → golden suite green

Owner delivered the real compare fixture
(`Sales_Register_Sep2026_v1.xlsx` → `..._FINAL.xlsx`, `expected.json`,
`reference_report_prototype.xlsx`), copied into `docs/fixtures/compare/`.
Rewrote `test/golden/compare.golden.test.ts` against the real schema; it now
passes (8 assertions): 8 real changes, 4 high (CHK-01/02/03/04), CHK-05 +
CHK-09, `mustNotFire` (CHK-06/07/10) silent, Summary has no real change
(ranges cancel), positional baseline exactly 89 on Sales Register.

Running against ground truth surfaced and fixed three real bugs:
1. **Dates read as plain numbers** — `XLSX.SSF` is undefined on SheetJS 0.18.5's
   ESM named import, so date-format detection silently failed and CHK-04 never
   fired. Replaced with a self-contained `isDateFormat` and always read number
   formats (`cellNF: true`).
2. **CHK-05 picked the wrong ID column** ("Invoice No" matched `/no/`), so the
   Desai-Traders two-GSTIN finding never fired. Now excludes the key column and
   prefers GSTIN/PAN headers.
3. **Positional baseline counted the title rows** — scoped it to the union of
   the data ranges (TDD §7.8); Sales Register is now exactly 89, not 90.
Plus a display fix: percentage columns ("GST %") are no longer ₹-formatted.
Full suite: 57 tests green.

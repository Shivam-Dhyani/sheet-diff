# 2026-10-08

## Project bootstrap — engine `@shivam-dhyani/sheet-diff`

First increment: the comparison engine (TDD milestones M0 + M2 + M3, compare
side). Merge/patch (M6/M7) and report rendering come in later increments.

### M0 — scaffold
- pnpm + TypeScript (strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`,
  no DOM lib per TDD §5.1), tsup (ESM+CJS+d.ts), Vitest, ESLint flat config,
  Prettier.
- Dependencies: `xlsx` (SheetJS CE, from the SheetJS CDN tarball per TDD §4),
  `fflate`, `@formulajs/formulajs`, `diff-sequences`; `officecrypto-tool`
  optional (decryption — browser support proven in spike S1 later).
- Copied `docs/PRD.md` and `docs/TDD.md` into the repo; added `logs/`,
  `.gitattributes` (logs `merge=union`), MIT `LICENSE`.

### Engine core (this increment)
- Compact IR: interned string pool + columnar typed arrays (`kind`/`num`/`str`),
  formula & numFmt maps, merges (TDD §6.1).
- Reader: format/encryption sniffing, CSV delimiter+encoding detection,
  SheetJS→IR adapter (dense, one sheet at a time), feature inventory via zip
  listing, decrypt wrapper, zip-bomb guards, progress + cooperative abort.
- Matching: table detection (header/data-range/total rows), sheet pairing,
  column matching, key detection (BR-C1 + composite), key-mode and order-mode
  row matching (FNV-1a hashing, Myers via `diff-sequences`, churn guard,
  similarity pairing, moved detection).
- Cell comparison: normalization (BR-C4/BR-C5), formula-aware kinds, positional
  baseline for the contrast line.
- Formula subsystem: tokenizer, reference model + relative form, translation
  (BR-C3), Pratt parser (Excel precedence), evaluator (memo + cycle detection),
  functions via `@formulajs/formulajs` + own `*IF(S)` criteria parser.
- Risk checks CHK-01..10 + ROW_ADDED/REMOVED/CELL_EDIT/RECALCULATED, ordering
  BR-C6.
- CLI: `sheet-diff old new [--json] [--key ...]` (+ `merge` placeholder wired
  to come with M6/M7).
